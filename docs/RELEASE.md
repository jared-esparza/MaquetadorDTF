Maquetador DTF 1.1.1 para Windows 10/11 x64, con instalador guiado en español y versión portátil.

- Nueva gama azul PKprint en controles, fondos, bienvenida, ayuda e iconos de Windows.
- Documentación actual sin referencias a herramientas de terceros.
- Separación inicial de 7 mm y formatos guardados conservados al actualizar.
- Los paquetes incluyen Electron y todos los recursos para el uso local; no requieren instalar Node.js ni descargar componentes durante la instalación.
- El portátil guarda sus preferencias en MaquetadorDTF-datos junto al ejecutable. Conserva esa carpeta al actualizar o moverlo.

**Versión preliminar sin firma.** Windows puede mostrar avisos o bloquear la ejecución según sus políticas. La comprobación de la versión anterior en Windows Sandbox sin Node y sin red quedó bloqueada por Control de aplicaciones. Consulta el informe de esta Release para conocer las pruebas realizadas sobre estos archivos concretos. Las pruebas de desarrollo y CI no equivalen a una validación en Windows limpio.

La licencia de reutilización del código propio está pendiente. Se incluyen los avisos de las dependencias.

Consulta USO-WINDOWS.md, VALIDACION-1.1.1.md y SHA256SUMS.txt. Antes de producir, imprime el PDF de calibración desde tu RIP al 100 % y comprueba el cuadrado de 100 × 100 mm.
